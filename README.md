# 两晋十六国 · 时空图志

个人历史学习用的互动网站，覆盖公元265—439年的30个关键年份及25个政权。

- 主线地图：年份、地图、关键事件同步联动。
- 政权年表：并排显示存续时间，包含西秦等政权的中断与复国。
- 学习导读：六个阶段，四本书的章节伴读，二赵、诸燕、三秦、五凉关系对照。
- 地图全屏：保留年份切换与政权详情；不支持系统全屏时使用窗口全屏。
- 新增373、414、418、427年节点，并更正部分地图时序与史料链接。
- 政权详情：都城、活动区域、主要人物、兴亡节点及相关史料。

## 地图说明

政权色块为手工概括的区域级教学示意，非精确历史疆界复原。海岸与河流采用现代地理底图，不能据此判断古代县级归属或计算政权面积。网站内提供年代口径与原始史籍、机构资料入口。

底图来源：[Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)（公共领域）。
